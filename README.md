# SplitBill

A lightweight, privacy-first web application designed for group dining. Calculate exact, fair food shares and proportionally apportion lump-sum taxes (VAT & SD) without accounts, apps, or data collection.

**Live → [ahnafpatwary.github.io/splitbill](https://ahnafpatwary.github.io/splitbill)**

---

## Features

- **Fast Group Assignment**: Add people and dishes in seconds.
- **Proportional Tax Distribution**: Accurately splits lump-sum VAT and Supplementary Duty (SD) based on individual food expenditure.
- **Instant Calculation**: Computes live as you type—no submit or calculate buttons.
- **Zero Overhead**: Single self-contained HTML file, no frameworks, no build tools, no tracking.
- **Tailored for Bangladesh**: Native BDT (৳) defaults.
